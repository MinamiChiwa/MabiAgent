MabiAgent 可為《新瑪奇 Mobile》繁體中文伺服器安排製作、採集與釣魚任務，並在執行期間修理裝備、補充材料及整理背包。

目前正式版本：0.6.3，可從 [Releases](https://github.com/MinamiChiwa/MabiAgent/releases) 下載。適用 Windows 10 / 11，64 位元。

封包擷取出現未關聯道具時，可在「倉庫 → 更新物品關聯」從已綁定的遊戲安裝目錄唯讀更新用戶端名稱表，不需安裝 Python 或重新啟動。工具只會為封包已出現的類型補上名稱，庫存數量與容器覆蓋仍來自封包；手動確認、清除和其他可信來源優先，同名多 ID 依具體類型區分。自動定位失敗時，可在「設定 → 資料同步 → 封包擷取設定」填寫遊戲程式所在目錄。

本工具供個人研究和測試使用；自動化操作可能造成帳號處罰、道具誤用或誤賣。本專案採用 [PolyForm Noncommercial 1.0.0](LICENSE) 授權，限非商業用途。

## 安裝

1. 將發行包解壓縮到自己的資料夾。
2. 按兩下 MabiAgent.exe。程式所需的 .NET 執行環境已包含在套件內。
3. 閱讀首次啟動的「使用前須知」。若提示缺少 Npcap，點擊對話方塊中的官方下載按鈕，安裝後重新開啟工具。Npcap 用於讀取背包與倉庫數量，也可前往 [官方下載頁](https://npcap.com/#download) 安裝。

## 先調整遊戲畫面

進入遊戲，開啟 **環境設定 → 圖形**，依序調整：

1. 選擇 **視窗模式**。
2. **解析度**選擇 **1280×960**。
3. **介面樣式**選擇 **PC**。
4. **調整比例**設為 **100%**。

套用設定後再開始任務。這些選項決定遊戲按鈕的位置與大小；點錯位置或找不到按鈕時，先核對這裡。

## 開始第一個任務

工具透過快速重進流程主動換圖擷取封包：主畫面 ESC → 點選「變更外貌/重生」 → 於重生頁面按 ESC → 於取消提示按空白鍵 → 角色重新載入。不需要私人劇場道具。

1. 登入遊戲，讓角色停在城鎮等方便操作的位置，保持遊戲視窗展開。
2. 在 MabiAgent 頂部點選「尋找」，選擇要操作的遊戲視窗。
3. 開啟「設定」，查看修理間隔、金幣留存、背包整理、精靈之翼和生活 VIP 的設定。
4. 回到「佇列」，點選「新增目標」，選擇任務並填寫目標量。
5. 點選「開始／繼續」。執行狀態和目前任務顯示在視窗頂部。

預設使用背景觸控，開始後可以切換到其他程式。遊戲最小化時任務會暫停，還原遊戲視窗後點選「開始／繼續」。若改用「前景滑鼠」，請讓遊戲保持在前景。

## 任務怎麼填寫

| 類型 | 填寫內容 | 執行方式 |
| --- | --- | --- |
| 製作 | 想取得的成品件數 | 先補材料，再前往設備加工和領取 |
| 採集 | 採集輪數 | **1 輪為 10 次採集嘗試**，實際材料數量取決於掉落 |
| 掛機釣魚 | 釣魚時長 | 先前往選定的釣魚場，再開始釣魚 |
| 原地釣魚 | 釣魚時長 | 請先站到可釣魚的位置；此模式預設關閉修理，保留背包整理 |

任務會依材料、加工時間和目前狀態自動安排；拖曳僅用於整理清單。

製作缺料時先從倉庫取料，倉庫不足再安排採集。空瓶和紙支援自動購買；其餘購買或戰鬥來源的材料請自行準備。不同設備可以同時加工，同一設備依序加工。

啟用釣魚任務時，請盡量關閉所有玩家暱稱顯示，減少辨識干擾。

兩種釣魚從第一次拋竿開始累計時長，回合間等待持續計時；暫停、檢查背包或轉入其他流程時暫停計時。首次拋竿先輕移，收竿後優先原地按空白鍵續拋，錯過約 2 秒的視窗或檢查背包返回後才補移動。定期負重檢查至少間隔 20 回合及 10 分鐘；背包已滿提示或連續拋竿無反應時可提前檢查。負重暫時讀不到會結束本次檢查，其他任務繼續。開始處於悠閒釣魚時自動切換為專心釣魚；全部任務完成後自動停止並保留完成進度。

拋竿後 20 秒仍未偵測到上鉤或有效進度條時，工具會輕移重拋，計時持續；手動暫停期間停止重試。

## 維護相關設定

**生活 VIP**：遊戲內生活 VIP 生效時開啟，新安排的加工按一半時長計算。新建任務和設定頁使用同一個開關。已安排的加工保留原本的預計完成時間；VIP 到期後請手動關閉。

**修理與金幣留存**：開啟自動修理並設定間隔。到達時間後，工具會在目前任務結束時前往修理。「金幣留存」是修理和購買後希望至少保留的金幣數。

**背包整理**：背包達到設定容量後，先點選遊戲內「整理」；仍然超重時，再以材料製作減重，最後販售允許出售的餘料。出售範圍為目前採集任務的目標材料，以及你在「指定販售材料與留存」加入的材料。

**材料留存**：「預設留存」用於沒有個別設定數量的材料。設備槽已佔用、材料達到留存下限時，暫停該材料的自動補採，繼續其他缺料任務或釣魚；空槽可製作時，再按本次所需材料補足。整理背包按留存下限和目前可製作用量中的較大值保留，超出的授權材料可販售。例如留存為 300、本次製作需要 500，就保留 500。超過整理比例會優先減重，仍有容量時繼續採集或釣魚。

**減少採集往返**：優先補齊空閒設備開工所缺的材料，再補庫存。同樣優先時，會留在目前採集點連續補料，達到所需數量後再換點；不會因每輪庫存比例變化反覆跑路。到期收貨、製作和維護仍會在目前原生批結束後接手。

**精靈之翼**：開啟後，導航時會依設定決定是否使用。請填寫希望保留的數量。

## 介面與迷你視窗

底部頁籤用於切換「佇列／倉庫／設定」。「佇列」用於新增目標、查看進度和待處理問題；「倉庫」依帳號顯示角色與庫存，並提供「更新物品關聯」；「設定」包含修理、整理、生活 VIP、資料同步、版本更新和「設定工作台」。配方和採集點從「新增目標」選擇，任務鏈與錨點從「設定 → 設定工作台」編輯。頂欄提供简体中文／繁體中文切換、「使用指南」、亮暗主題、資料目錄、GitHub、贊助和版本更新入口；「使用指南」以內建視窗呈現 Markdown，支援標題、清單、表格、程式碼與連結，可在視窗內切換簡體／繁體並保留閱讀位置。頂欄更新按鈕僅在發現新版本時顯示，手動檢查請前往「設定 → 版本更新」。按住頂部空白處可拖曳視窗，按兩下可最大化或還原。

點選執行列的「迷你視窗」，主介面會收成一張小卡片，保留目前任務、進度和執行按鈕。訊息按鈕旁的數字表示待處理問題數，點選可查看詳細資料。「展開詳細資料」可查看後續任務和遊戲視窗選擇。圖釘控制置頂，右側返回按鈕開啟主視窗。

常用快速鍵：Ctrl+N 新增目標，Ctrl+1～Ctrl+3 切換佇列、倉庫和設定，Ctrl+F 搜尋，Ctrl+M 進入迷你視窗，Delete 刪除所選任務。

## 暫停和停止有什麼不同

預設全域暫停快捷鍵為 **Ctrl+Alt+F9**，可在「設定 → 操作方案 → 全域暫停快捷鍵」直接錄入並套用單鍵、組合鍵或滑鼠鍵。暫停保留任務進度和操作紀錄，點擊「繼續」恢復；再次按暫停鍵保持暫停。暫停與停止不能使用同一快捷鍵，設定區域內停用兩者，避免錄入及套用時誤觸。

預設全域停止快捷鍵為 **Ctrl+Alt+F10**。在「設定 → 操作方案 → 全域停止快捷鍵」點選「錄入」，按下鍵盤單鍵或組合鍵，或在輸入框內按滑鼠左鍵、右鍵、中鍵、側鍵、捲動滾輪，再點選「套用快捷鍵」。修飾鍵單獨使用時放開後錄入；「取消錄入」或移開焦點取消本次擷取。設定區域內暫停停止回應，點選錄入、取消及套用不會誤觸停止或改寫草稿；移開滑鼠及焦點後恢復。鍵盤組合已被占用時會顯示錯誤並保留原綁定。切換到其他程式、介面忙碌或任務等待期間也能觸發「停止全部」。

**暫時離開、處理背包或調整任務時，使用「暫停」。** 進度會保留，回來後點選「開始／繼續」。

**想讓整份佇列從頭重新執行時，使用「停止全部」。** 它會清除執行進度、自動補充材料及結果待確認記錄，保留手動新增的目標和設定。遊戲中已完成的購買、出售、加工仍然有效，再次開始可能再次花費金幣或材料。

遇到結果待確認提示時，請先到遊戲中確認實際情況，再處理提示或決定是否重新開始。

## 庫存顯示「未知」怎麼辦

查看「設定 → 資料同步 → 封包擷取設定」，確認 Npcap、網路卡和處理程序綁定狀態正常。背包與倉庫數量來自遊戲網路資料，剛開始監聽或切換角色後可能需要重新整理。

工具通常透過快速重進角色重新整理庫存。遊戲更新後，工具會從所選遊戲處理程序自動找到用戶端檔案並解析新版本。讀取失敗時，在封包擷取設定中依提示填寫遊戲程式所在目錄後重試。

## 新增自己的採集地點

開啟「設定 → 設定工作台…」，在任務鏈分類中從相似範本新增採集，修改目標和對應辨識圖片。這裡的「錨點」是供工具辨識按鈕或頁面的小圖。

先暫停主任務，再測試新流程。新地點的按鈕位置、名稱或頁面與範本不同時，都需要一起調整。

## 更新與備份

從頂欄「資料目錄」開啟存放設定的資料夾。佇列、設定、帳號紀錄和自己編輯的任務鏈都在這裡。

也可以在「設定 → 版本更新」檢查更新。啟動時檢查可以關閉；檢查只讀取版本資訊，不會自動下載或取代。確認下載後依發行清單只取有變更的檔案；目標版本未提供逐檔清單時會下載完整套件並標示「完整套件」。確認安裝後會先暫停任務、釋放遊戲輸入，再由獨立更新程式備份並取代檔案，失敗時逐項回復。`data/`、佇列、設定、帳號、使用者任務鏈與待核帳不會被更新覆蓋。鏡像只傳輸檔案；清單與雜湊來自官方通道，鏡像失敗時回復官方位址。

手動更新時先結束程式並備份資料目錄。解壓縮新版本後，將原本的 data 資料夾複製到新版本目錄，再啟動新版本。一次只執行一個版本。自選資料位置的玩家可透過 --state-dir 參數繼續使用原路徑，詳細指令見開發指南。

## 常見問題

**找不到遊戲視窗**：確認遊戲已開啟並展開；有多個用戶端時，在下拉式清單選擇對應視窗。

**點擊位置不對，或一直找不到按鈕**：核對繁體中文介面、視窗模式、1280×960、PC 介面樣式和 100% 比例，再查看執行列中的具體提示。

**採集很多輪仍然缺料**：輪數代表嘗試次數。稀有副產物掉率較低，可能需要較長時間。

**任務停住**：查看頂部狀態和訊息按鈕中的提示。背包空間、材料不足、遊戲最小化、某次操作結果待確認，都可能需要你處理後繼續。
