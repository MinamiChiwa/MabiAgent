# MabiAgent

MabiAgent 可以为《洛奇 Mobile》繁体中文服安排生产、采集和钓鱼任务，并在运行期间修理装备、补充材料和整理背包。

当前开发版本：0.6.0；下载以 [Releases](https://github.com/MinamiChiwa/MabiAgent/releases) 实际版本为准。适用 Windows 10 / 11，64 位。

抓包出现未关联道具时，可在“仓库 → 更新物品关联”从已绑定游戏目录只读更新客户端名称表，无需安装 Python 或重启。工具只为已抓包类型补名，库存数量和容器覆盖仍来自抓包；手动确认、清除和其他可信来源优先，同名多 ID 按具体类型区分。自动定位失败时，可在“设置 → 数据同步 → 抓包设置”填写游戏程序所在目录。

本工具供个人研究和测试使用；自动化操作可能引发账号处罚、道具误用或误卖。项目采用 [PolyForm Noncommercial 1.0.0](LICENSE) 许可，限非商业用途。

## 安装

1. 将发布包解压到自己的文件夹。
2. 双击 MabiAgent.exe。程序所需的 .NET 环境已包含在包内。
3. 阅读首次启动的“使用前须知”。如果提示缺少 Npcap，点击弹窗中的官方下载按钮，安装后重新打开工具。Npcap 用于读取背包和仓库数量，也可前往 [官网下载页](https://npcap.com/#download) 安装。

## 先调整游戏画面

进入游戏，打开 **环境设定 → 图形**，依次调整：

1. 选择 **视窗模式**。
2. **解析度**选择 **1280×960**。
3. **界面样式**选择 **PC**。
4. **调整比例**设为 **100%**。

应用设置后再开始任务。这些选项决定了游戏按钮的位置和大小；点错位置或找不到按钮时，先核对这里。

## 开始第一个任务

工具通过快速重进流程主动换图抓包：主界面 ESC → 点击“變更外貌/重生” → 重生页按 ESC → 取消提示按空格 → 角色重新加载。不再需要私人剧场道具。

1. 登录游戏，让角色停在城镇等方便操作的位置，保持游戏窗口展开。
2. 在 MabiAgent 顶部点击“查找”，选择要操作的游戏窗口。
3. 打开“设置”，查看修理间隔、金币留存、背包整理、精灵之翼和生活 VIP 的设置。
4. 回到“任务队列”，点击“新增目标”，选择任务并填写目标量。
5. 点击“开始／继续”。运行状态和当前任务显示在窗口顶部。

默认使用后台触控，运行后可以切到其他程序。游戏最小化时任务会暂停，还原游戏窗口后点击“开始／继续”。如果改用“前台鼠标”，请让游戏保持在前台。

## 任务怎么填写

| 类型 | 填写内容 | 运行方式 |
| --- | --- | --- |
| 生产 | 想得到的成品件数 | 先补材料，再前往设备加工和领取 |
| 采集 | 采集轮数 | **1 轮为 10 次采集尝试**，实际材料数量取决于掉落 |
| 挂机钓鱼 | 钓鱼时长 | 先前往选定的钓鱼场，再开始钓鱼 |
| 原地钓鱼 | 钓鱼时长 | 请先站到可钓鱼的位置；该模式默认关闭修理，保留背包整理 |

生产缺料时先从仓库取，仓库不足再安排采集。空瓶和纸还支持自动购买；其余购买或战斗来源的材料请自行准备。不同设备可以同时加工，同一设备按顺序加工。

钓鱼抛竿后 20 秒内若未检测到上钩或有效进度条，工具会重新轻移并抛竿，继续原钓鱼时长；未成功起竿的等待不计入有效时长，手动暂停期间不重试。

## 维护相关设置

**生活 VIP**：游戏内生活 VIP 生效时打开，新安排的加工按一半时长计算。新建任务和维护页使用同一个开关。已经安排好的加工保留原来的预计完成时间；VIP 到期后请手动关闭。

**修理与金币留存**：打开自动修理并设置间隔。到时间后，工具会在当前任务结束时前往修理。“金币留存”是修理和购买后希望至少剩下的金币数。

**背包整理**：背包达到设定容量后，先点击游戏内“整理”；仍然超重时，再用材料生产减重，最后出售允许出售的余料。出售范围为当前采集任务的目标材料，以及你在“指定贩售材料与留存”中加入的材料。

**材料留存**：“默认留存”用于没有单独设置数量的材料，队列还需要的材料也会预留。例如默认留存为 300，而生产需要 500，就按 500 留存。整理后仍然放不下时，任务会暂停，请在游戏中腾出空间再继续。

**精灵之翼**：打开后，导航时会按设定决定是否使用。请填写希望保留的数量。

## 界面与迷你窗口

底部页签用于切换“队列／仓库／设置”。“队列”用于新增目标、查看进度和待处理问题；“仓库”按账户显示角色与库存，并提供“更新物品关联”；“设置”包含修理、整理、生活 VIP、数据同步、版本更新和“配置工作台”。配方和采集点从“新增目标”选择，任务链与锚点从“设置 → 配置工作台”编辑。顶栏提供简体中文／繁體中文切换、“使用指南”、亮暗主题、数据目录、GitHub、赞助和版本更新入口；切换界面语言后，“使用指南”会打开当前语言的说明。按住顶部空白处可拖动窗口，双击可最大化或还原。

点击运行栏的“迷你窗口”，主界面会收成一张小卡片，保留当前任务、进度和运行按钮。消息按钮旁的数字表示待处理问题数，点击可查看详情。“展开详情”可查看后续任务和游戏窗口选择。图钉控制置顶，右侧返回按钮打开主窗口。

常用快捷键：Ctrl+N 新增目标，Ctrl+1～Ctrl+3 切换队列、仓库和设置，Ctrl+F 搜索，Ctrl+M 进入迷你窗口，Delete 删除所选任务。

## 暂停和停止有什么区别

**暂时离开、处理背包或调整任务时，用“暂停”。** 进度会保留，回来后点击“开始／继续”。

**想把整份队列从头再跑时，用“停止全部”。** 它会清除执行进度、自动补料和结果待确认记录，保留手动添加的目标和设置。游戏里已经完成的购买、出售、加工仍然有效，再次开始可能再次花费金币或材料。

遇到结果待确认提示时，请先去游戏里看实际情况，再处理提示或决定是否重新开始。

## 库存显示“未知”怎么办

查看“设置 → 数据同步 → 抓包设置”，确认 Npcap、网卡和进程绑定状态正常。背包与仓库数量来自游戏的网络数据，刚开始监听或切换角色后可能需要刷新。

工具通常通过快速重进角色刷新库存。游戏更新后，工具会从所选游戏进程自动找到客户端文件并解析新版本。读取失败时，在抓包设置中按提示填写游戏程序所在目录后重试。

## 添加自己的采集地点

打开“设置 → 配置工作台…”，在任务链分类中从相似模板新建采集，修改目标和对应识别图片。这里的“锚点”是供工具识别按钮或页面的小图。

先暂停主任务，再测试新流程。新地点的按钮位置、名称或页面和模板有差别时，都需要一起调整。

## 更新与备份

从顶栏“数据目录”打开存放设置的文件夹。队列、设置、账号记录和自己编辑的任务链都在这里。

也可以在“设置 → 版本更新”检查更新。启动时检查可以关闭；检查只读取版本信息，不会自动下载或替换。确认下载后按发布清单只取发生变化的文件；旧版本没有逐文件清单时会下载完整包并标注“完整包”。确认安装后会先暂停任务、释放游戏输入，再由独立更新程序备份并替换文件，失败逐项回滚。`data/`、队列、设置、账户、用户任务链与待核账不会被更新覆盖。镜像只传输文件；清单与哈希来自官方通道，镜像失败时回退官方地址。

手动更新时先退出程序并备份数据目录。解压新版本后，将原来的 data 文件夹复制到新版本目录，再启动新版本。一次只运行一个版本。自选数据位置的用户可通过 --state-dir 参数继续使用原路径，详细命令见开发指南。

## 常见问题

**找不到游戏窗口**：确认游戏已经打开并展开；有多个客户端时，在下拉列表选择对应窗口。

**点击位置不对，或一直找不到按钮**：核对繁体中文界面、视窗模式、1280×960、PC 界面样式和 100% 比例，再查看运行栏中的具体提示。

**采集很多轮仍然缺料**：轮数表示尝试次数。稀有副产物掉率较低，可能需要较长时间。

**任务停住了**：查看顶部状态和消息按钮里的提示。背包空间、材料不足、游戏最小化、某次操作结果待确认，都可能需要你处理后继续。
