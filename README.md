# MabiAgent

MabiAgent 是给《洛奇 Mobile》（繁体中文服）用的 Windows 桌面辅助工具，用来排队执行生活类任务：生产、采集、钓鱼，以及途中的修理、补料和背包整理。它通过识别游戏画面来判断页面，用后台触控或鼠标操作游戏，并通过监听本机网络数据读取背包和仓库数量。

当前版本：0.5.1

## 运行环境

- Windows 10 / 11，64 位。
- 游戏客户端为繁体中文界面，客户区按 1280×960 标定。其他分辨率或语言可能识别失败，需要重新标定。
- 如需读取背包与仓库数量，需要另外安装 [Npcap](https://npcap.com/)（安装时保持默认选项即可）。不装 Npcap 也能启动，但库存会显示为“未知”，依赖库存的功能会暂停等待。
- 发布包自带 .NET 运行环境，不需要另装 .NET、Python 或浏览器组件。

## 安装

1. 下载发布包并解压到一个**可写**的目录，例如 `D:\Tools\MabiAgent`。不要放在 `C:\Program Files` 这类需要管理员权限的位置。
2. 双击 `MabiAgent.exe` 启动。
3. 首次启动会弹出使用前须知，并只读检测 Npcap；未检测到可用组件或网卡时，弹窗提供说明和 [官方下载页](https://npcap.com/#download)。已可用时不显示 Npcap 提醒。确认须知后进入主界面，后续启动不再重复提示。启动本身不会操作游戏。

## 第一次使用

1. 进入游戏，让角色站在安全的位置。游戏窗口不要最小化（被其他窗口挡住没关系）。
2. 在工具顶部的运行栏中点击“查找”，然后在下拉框里选中游戏窗口。
3. 打开“维护设置”，按自己的情况确认修理、金币留存、材料留存、精灵之翼和生活 VIP。设置会自动保存。
4. 回到“任务队列”，点击“新增目标”，选择任务类型并填写数量，加入队列。
5. 点击“开始／继续”。

工具默认使用“后台触控”方式输入，开始后你可以切到别的程序，游戏不需要保持在前台。切换输入方式后，需要重新点一次“开始／继续”。

## 界面说明

主窗口没有系统标题栏，按住顶部空白处可以拖动窗口，双击可以最大化，右上角是最小化、最大化和关闭按钮。左侧是导航，右侧顶部是运行栏，任何页面都能看到。

| 区域 | 用途 |
| --- | --- |
| 运行栏 | 运行状态、当前任务、游戏窗口选择、开始／暂停／停止，以及待处理问题 |
| 任务队列 | 你添加的目标。可以多选、拖动排序、直接在表格里改计划数量 |
| 材料配方 | 查看所有配方的设备、产量和耗时，双击可直接创建任务 |
| 维护设置 | 输入方式、主题、修理、购买、背包整理、精灵之翼、数据同步 |
| 账户道具 | 按账号和角色查看背包与仓库数量，确认道具名称 |
| 任务链／锚点调试 | 在独立窗口中编辑采集流程和识别模板，一般用户用不到 |

所有表格的列宽默认按内容自动调整，拖动表头之间的分隔线可以改宽度，点表头可以排序。

常用快捷键：

| 按键 | 作用 |
| --- | --- |
| `Ctrl+F` | 搜索当前页面 |
| `Ctrl+M` | 切换到迷你窗口 |
| `Delete` | 删除队列中选中的任务 |
| `Esc` | 关闭对话框或抽屉 |

## 迷你窗口

挂机时不想让主窗口占地方，可以点运行栏里的“迷你窗口”按钮（或按 `Ctrl+M`）。主窗口会隐藏，屏幕上只留下一个小卡片：

- 第一行：运行状态、待处理问题数量。问题数量的红点可以点开查看详情。
- 第二行：当前任务名称和进度条。
- 第三行：开始／继续、暂停、停止全部。“停止全部”会先让你确认。
- 点卡片底部的“展开”可以看到队列前几项、监听状态和游戏窗口选择，再点一次收起。
- 卡片默认置顶，可以用图钉按钮取消置顶。按住标题栏可以拖动位置。
- 点“返回主窗口”或双击标题栏回到完整界面。

迷你窗口和主窗口用的是同一套数据，在哪边操作效果都一样。关闭迷你窗口只会回到主窗口，不会退出程序。

## 任务类型

**生产**：按成品件数计算。工具会根据配方算出缺多少材料，缺的先从仓库取，仓库也不够时再安排采集。同一种设备的任务排队依次进行，不同设备可以同时加工，加工完成后自动领取。

**采集**：按轮数计算，**1 轮 = 10 次采集尝试**。轮数不等于材料数量，稀有材料可能要很多轮才出。

**挂机钓鱼**：先自动移动到选定的钓鱼场，再按设定时长钓鱼。

**原地钓鱼**：角色已经站在能钓鱼的地方时用这个，省去移动。默认不修理，仍会按背包设置整理。

## 维护设置

**生活 VIP**：默认关闭。游戏内生活 VIP 生效时打开，之后新安排的加工按一半时长计算。已经提交的加工槽不会因为改这个开关而重新计算。工具不会自动判断 VIP 是否到期，到期后请自己关掉。

**修理**：开启后按设定间隔检查装备，在当前任务结束后修理。修理和购买都会保留“金币留存”设置的金币数。

**自动购买**：只会自动买空瓶和纸，且先从仓库取，仓库不够才买。其他材料不足时只提示，不会购买。

**背包整理**：背包达到设定容量后，优先用材料生产来腾空间，再出售余料。出售只针对两类材料：当前采集目标，以及你在“指定贩售材料与留存”中明确加入的材料。其他材料哪怕超出默认留存，也不会被卖掉。如果既不能卖也不能靠生产腾空间，任务会暂停交给你处理，工具不会自动存仓。

**精灵之翼**：开启后远距离移动时使用，用完至少保留你设定的数量。

**数据同步**：查看抓包监听状态，开始或停止监听，打开“抓包设置”选择网卡。

## 暂停、停止与待处理

- **暂停**：保留当前进度，点“开始／继续”从原处接着做。
- **停止全部**：清掉所有执行中的进度、自动补料、待核账记录和消费记录，只保留你手动添加的任务和设置。**停止不会撤销游戏里已经发生的操作**，重新开始后可能再次消耗材料。
- 游戏最小化时会自动暂停，还原后需要手动点继续。用前台鼠标方式时，游戏失去焦点也会暂停。
- **待处理问题**：运行栏和迷你窗口都会显示需要你介入的问题，例如背包满了无法处理、某次购买结果无法确认。已经发出但结果不明确的消费操作不会被自动重试，请先到游戏里核实，再决定怎么处理。

## 库存数据是怎么来的

背包和仓库的数量只来自网络数据监听，不会用屏幕上的数字代替。没有拿到完整数据时显示“未知”，工具不会把“未知”当成 0。

想主动刷新库存，可以在“抓包设置”里点“私人剧场刷新”。确认角色身上没有某个道具时，也可以用“重新登录”刷新。不同账号、不同角色的仓库数据分开保存。

## 自定义采集地点

打开“任务链”工作台，选“从模板新建采集”，挑一个最相似的地点作为模板，只改目标列表和识别图等不同的地方，公共的导航和采集步骤直接复用。新地点必须配好能稳定识别的图片，只改名字是不够的。

调试流程前请先暂停主任务。

## 数据目录与更新

你的队列、设置、账号数据和任务链都存在数据目录里，可以从主窗口左下角“数据目录”打开。

更新版本时：

1. 先退出旧版本。
2. 备份数据目录。
3. 解压新版本，用 `--state-dir` 参数指向原来的数据目录启动，或把数据目录复制过去。

不要同时运行两个版本，也不要让两个程序共用同一个数据目录。发布包本身不含任何队列、账号或调试记录。

数据目录不会无限变大，工具会自动清理：

- 运行日志和故障记录到达上限后自动轮换，只保留最近的内容。
- 每条任务链只保留最近 20 个历史版本。
- 删除的任务链先保留 30 天，方便找回，之后在启动时清除。
- 锚点调试的修改历史只保留最近 50 条（安装时的预设版本始终保留）。

## 常见问题

**点“查找”后找不到游戏窗口。**
确认游戏已经启动且没有最小化。如果开了多个客户端，下拉框里会列出全部，选中你要控制的那个。

**库存一直显示“未知”。**
检查是否安装了 Npcap，再到“维护设置 › 数据同步 › 抓包设置”里看网卡和进程绑定状态。切换角色后需要重新同步一次。

**开始后没有反应，或卡在某个页面。**
先确认游戏客户区是 1280×960、繁体中文界面。然后看运行栏的待处理问题和状态说明。识别超时会有限次重试，失败后暂停等你处理。

**采集了很多轮，材料还是不够。**
1 轮是 10 次采集尝试，不是 10 个材料。稀有材料掉率低，需要更多轮。

**停止后重新开始，材料被多扣了。**
“停止全部”不会回滚游戏内已经完成的动作。如果只是想临时中断，请用“暂停”。

## 适用范围与已知限制

- 识别资源针对繁体中文界面和 1280×960 客户区。其他布局需要重新标定。
- 网络波动会触发有限次重试。识别或导航失败不一定是材料不足，请看具体提示。
- 程序内的离线自检只验证程序和配置能正常加载，不代表在任何角色、地图、分辨率下都能正常运行。
