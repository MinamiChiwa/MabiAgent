# MabiAgent 0.5.0

Windows 桌面生活任务工具。通过游戏画面识别、后台输入和被动抓包库存，安排采集、钓鱼、生产与维护。界面使用 Avalonia、Semi.Avalonia 和 Ursa.Avalonia。

## 开始使用

1. 解压纯净发布包到可写目录，运行 `MabiAgent.exe`。发布包包含 .NET 运行环境；抓包需要单独安装 Npcap。
2. 进入游戏，保持游戏窗口可见且不最小化，在工具中选择游戏窗口。
3. 在“新增目标”选择生产、采集或钓鱼，填写目标后加入队列。
4. 核对“维护设置”的修理、金币与材料留存、精灵之翼以及生活 VIP，再点击“开始／继续”。

默认使用后台触控，不要求游戏保持前台。切换输入方案后请重新开始。最小化或手动暂停后，需要显式继续。首次启动不自动操作游戏。

## 任务与维护

- **生产**按产物件数；同设备串行、不同设备可并行，工具按材料缺口安排补采并在加工完成后领取。
- **采集**按轮数，**1轮＝10次采集尝试**，不保证每轮材料产量。稀有副产物可能需要多轮。
- **挂机钓鱼**先导航到选定地点；**原地钓鱼**要求角色已在可钓鱼位置，省去导航，默认不修理，仍按设置整理背包。
- **生活 VIP**默认关闭。游戏内生活 VIP 已生效时开启，新安排的加工按标准时长的一半计算。新建任务和维护页共用此设置；内置与自定义配方均适用。已提交槽位的到期记录保持不变，工具不会自动判断 VIP 到期。
- **材料留存**仅作用于当前采集目标和“指定贩售材料与留存”中明确加入的材料。不相关材料不会因超过默认下限而自动出售。实际留存同时满足队列需求；无法出售或生产以释放背包时，暂停交由玩家处理，不自动存仓。
- 缺料优先从仓库取料。只有空瓶和纸可自动购买；其他购买或战斗来源不足时提示，独立任务继续。

库存数量只取抓包。未取得完整库存时显示未知，不以屏幕数字代替。刷新优先使用私人剧场；确认角色没有该道具时可用同角色重新登录。账号和角色的仓库数据分开保存。

## 暂停、停止和待处理

“暂停”保留当前进度；“停止全部”清除执行进度、自动补料、核账和消费意图，保留手工目标与设置。**停止不会回滚游戏内已发生的操作，重新开始可能再次消耗材料。**

待处理区显示需要玩家介入的当前问题。普通加工等待和已恢复问题不长期堆积。已发送但结果不明的消费不自动重复，请核实游戏后处理。

## 自定义采集与调试

在任务链工作台选择“从模板新建采集”，选择相似地点，仅调整目标列表、详情身份与目标身份等差异，复用公共导航和采集步骤。新地点需要对应的稳定识别图；改名称不能代替识别配置。高级编辑可展开完整步骤。

锚点选择器先展示已选引用，完整锚点库折叠，可搜索添加。移除引用不会删除公共锚点。调试前暂停主任务，按需要测试识别、步骤或整链。

## 数据与更新

用户队列、设置、账户及任务链保存在数据目录，可从左下角“数据目录”打开。更新前退出旧程序并备份自己的数据；不要让两个实例同时使用一个数据目录。纯净包不包含任何现有队列、账号或调试状态。

界面左下角“GitHub 仓库”打开项目私有仓库，需要仓库访问权限。版本从 0.5.0 开始按末位递增。

## 适用范围

当前资源面向繁体中文游戏界面与 1280×960 客户区基准；其他布局可能需要重新标定。网络波动会触发有限重试；不能把所有识别或导航失败都当作材料不足。离线自检验证程序和配置，不等于任意角色、地图、分辨率的实机保证。

开发与构建见 [开发指南](docs/DEVELOPMENT.md)。游戏及第三方组件的权利属于各自所有者；第三方许可见模型许可与发布包的第三方说明。
